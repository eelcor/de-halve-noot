# De Halve Noot

Een virtuele jazzpianist die in de geest van Thelonious Monk improviseert in een rokerig café. Elke maat wordt in de browser ter plekke bedacht: een blues van 12 maten in B♭ met stride-linkerhand, botsende kleine secundes, heletoonsloopjes, verschoven klemtonen en veel stilte.

Speel hem op: https://eelcor.github.io/de-halve-noot/

## Geluid

De pianoklank gebruikt opnames uit de **Salamander Grand Piano** van Alexander Holm, uitgebracht onder de [Creative Commons Naamsvermelding 3.0](https://creativecommons.org/licenses/by/3.0/)-licentie. De samples zijn als base64 in `index.html` opgenomen. De galm en de pratende gasten worden met de Web Audio API in de browser gemaakt.
